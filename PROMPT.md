Need to solve the two problems in the puzzles directory:
- `2025-06-puzzle.md`
- `2005-10-puzzle.md`

The puzzles are from the Advent of Code project. You should solve one puzzle at a time. Finish one before moving on to the next.

The test inputs are in the `-example.md` files, and the real inputs are in the `-input.md` files. Each puzzle has two parts, and you need to output the answers for each part separately. You can use the example input to test your implementation first, then use the real input to calculate and output the results.

The requirement is to implement it in Rust, compile it into an executable file, and output the final results after running it.
